  has explanatory text. Existing discovery, installed/missing/custom-path
  detection and all change/persist handlers are reused. No new provider settings
  screen, picker list, account store or transport selector was introduced.
- The panel explains the current headless route and unavailable ACP/Standard
  approvals. `agentMetadata.ts` supplies honest Grok Standard and Read-Only
  tooltips while retaining the separate labels. Read-Only requests CLI plan mode
  with shell denied; it is not an all-tools-off mode or a filesystem sandbox.
  Production ACP routing and permission certification remain pending in [[03]].
- `MainPanelHeader.tsx` shows the existing canonical profile label when context
  size is unknown. It reuses withheld/ambiguous credential attribution and does
  not invent an account or context-window value. Memory and session buttons keep
