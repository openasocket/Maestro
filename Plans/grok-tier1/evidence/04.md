## Implementation and boundaries

- `listSessions(projectPath, sshConfig, accountDir)` selects the account home.
  Paginated listing forwards `SessionListOptions.configDir` and uses the
  existing base pagination helper. The same resolved sessions directory flows
  through cwd enumeration, session enumeration and metadata reads.
- `readSessionMessages(..., { configDir }, sshConfig)` reads that account;
  `getSessionPath(projectPath, sessionId, sshConfig, accountDir)` constructs a
  path in that same root. The shared interface adds only optional fields and
  trailing arguments, retaining existing call positions.
- `searchSessions(projectPath, query, mode, sshConfig, accountDir)` resolves an
  explicit selection once, then delegates through an immutable account-bound
  Grok reader to inherited search. Both metadata and message loading use that
  root. No registered-instance mutation, duplicate search algorithm or changes
  to other providers are needed. The optional constructor scope also reaches
  list, paginated list, read and path methods.
- Phase 02's canonical `resolveAgentAccountDir()` replaces the two local-only
  Grok home helpers. Explicit roots never consult host `GROK_HOME`; explicit
  blank/whitespace roots select the provider default. Omitted scope retains
  local host-environment/default behavior. Local tilde/relative paths use the
  canonical resolver; SSH roots stay remote and use POSIX joins without local
  home expansion or environment fallback.
- A missing selected root yields the existing empty list/read/search results.
  Path lookup remains a best-effort synchronous path in the selected root; it
  does not assert file existence or search another account. No fallback to an
  installed default account is added.

## Implementation and review

- Extended the existing Grok path validator to accept opaque native IDs instead
  of requiring UUIDs. Reject empty names, dot/dot-dot components, raw slash or
  backslash and NUL before directory joins. IDs remain literal, including percent
  escapes; they are never sanitized or decoded into a different session name.
- Apply validation to discovered session names, direct lookup before filesystem
  access, metadata loading and synchronous path lookup. Validate raw cwd folder
  components before strict percent decoding; reject malformed escapes, decoded
  NUL and decoded dot/dot-dot path components before joins. Encoded slashes,
  spaces, Unicode, apostrophes and either percent-hex case remain supported.
  Path lookup returns null for malformed Unicode instead of throwing URIError.
- Use the validated directory's ID and decoded cwd for returned history identity.
  Stale/malicious summary identity cannot redirect later search/read operations
  to another session or project. Removed the now-unused summary identity fields
  from its consumed-fields interface.
- Preserve local macOS `/private/var`, `/private/tmp` and `/private/etc` aliases.
  SSH filtering compares remote paths without assuming these aliases exist on
  the unknown remote OS. Keep trailing-slash cleanup and correctly include
  descendants when the requested project is the POSIX root.
- Continue using `path.posix.join()` for SSH and `readDirRemote()`,
  `readFileRemote()` and `statRemote()`. Their canonical
  `shellEscapeRemotePath()` handles remote tilde expansion and quoted path text;
  the adapter never resolves remote paths through local filesystem calls.
  Remote directory symlinks retain the shared helper's existing behavior. This
  is lexical path validation, not a new realpath/symlink containment guarantee.
- Preserve `mapWithConcurrency()` with the existing remote limit of six session
  workers and sequential reads inside each worker. Expected remote missing or
  inaccessible paths retain honest empty/null results; unexpected SSH failures
  retain warning/Sentry context. Reuse `isExpectedSessionReadError()` at all
  local catches instead of repeating the narrower three-code checks.

Independent source review confirmed the account/root flow and join boundaries.

change rejects dot components so that malformed cwd cannot masquerade as a
project descendant. No installed account files, credentials, native provider
