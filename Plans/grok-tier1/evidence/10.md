1. `create-agent --type` help was a hand-written list (`claude-code, codex, opencode,
factory-droid, copilot-cli, antigravity, gemini-cli, qwen3-coder`) that omitted
   `grok` (and `hermes`, `pi`, `omp`) although the validator already accepted every
   `AGENT_IDS` entry except `terminal`. `create-agent.ts` now exports
   `CREATE_AGENT_TYPES` (the validator's own list) and `index.ts` builds the help text
   from it, so the accepted and advertised sets cannot drift. This is a discoverability
   fix only: acceptance of `--type grok` was already present and is unchanged.

   although phase 08 added `grok` to `LEARN_AGENTS` (`pianola-learn.ts:33`, Grok session
   root via `resolveAgentAccountDir`). The help now names `grok` as an opt-in value and
   states the unchanged default (`claude-code,codex`). The help string adds no
   functionality; the crawler is phase 08's.
